## Detailed description

Follow topics, not channels.

Topic Digest for YouTube searches YouTube for recent videos on a topic you choose, filters out
Shorts and likely clickbait, reads the available timed transcripts, and generates a structured
summary for each video plus a cross-video synthesis. Every summary includes clickable
timestamps so you can jump to the part that matters.

How it works:

- Add a topic and run a scan from the side panel.
- The extension searches YouTube, screens candidates, and fetches transcripts.
- Summaries are generated by Google's Gemini API using your own API key.
- Results are saved in your browser, with clickable `[MM:SS]` timestamps.
- Star topics, pin channels, and export/import a JSON backup of your topics and digests.

Built to run on its own:

- No account and no developer server. The extension works without a separate app or local
  service.
- Bring your own Gemini API key. It is stored only on your device in
  `chrome.storage.local` and is never included in backups or Chrome sync.
- Topics, pins, and preferences live in `chrome.storage.sync` (and may sync through your own
  Chrome profile). Digests and counters live in IndexedDB.
- The only network destinations are YouTube and Google's Gemini API, for actions you start.

Requirements and limits:

- You need a Gemini API key. Usage of the Gemini API is subject to Google's terms and any
  quotas or charges that apply to your key.
- Summaries are generated automatically and may contain mistakes. Review the source video when
  accuracy matters.
- YouTube access can change; if YouTube changes its web API, some features may stop working
  until the extension is updated.

This is an independent, unofficial project. It is not affiliated with, endorsed by, or
sponsored by YouTube or Google LLC. YouTube is a trademark of Google LLC.
